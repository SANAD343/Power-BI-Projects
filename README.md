# 📊 Power BI Projects

Welcome to my **Power BI Portfolio Repository**!  
This repo showcases a collection of interactive dashboards and reports I’ve built to transform raw data into actionable insights.

---

## 🧩 About Power BI
[Power BI](https://powerbi.microsoft.com/) is a business analytics service that provides interactive visualizations and business intelligence capabilities with an easy-to-use interface.  
I use Power BI to:
- **Connect** to diverse data sources (SQL, Excel, APIs, etc.)
- **Clean & transform** data with Power Query (ETL)
- **Model** relationships using DAX
- **Visualize** key KPIs with interactive dashboards
